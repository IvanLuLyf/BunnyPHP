# Language / i18n（多语言）

## 约定

- 语言包目录：
    - 应用：`APP_PATH/lang/`
    - 框架：`BUNNY_PATH/lang/`
- 文件名：**全小写**，例如 `en.json`、`zh.json`、`zh-cn.json`

## locale 选择顺序

依次尝试：

1. `?lang=`
2. cookie：`bunny_lang`
3. session：`bunny_lang`
4. header：`Accept-Language`
5. 默认：`en`

## 地区包 fallback

如果请求的是 `zh-cn`：

- 先找 `zh-cn.json`
- 没有则回退 `zh.json`
- 再没有则回退 `en.json`

应用语言包找不到 key 时，会回退到框架语言包。

## 使用方式

```php
<?= BunnyPHP\Language::get('login') ?>
```

支持带参数插值（`{name}` 风格）：

```php
<?= BunnyPHP\Language::get('welcome', ['name' => $nickname]) ?>
```
