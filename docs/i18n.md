# Language / i18n

## Convention

- Language pack directories:
    - App: `APP_PATH/lang/`
    - Framework: `BUNNY_PATH/lang/`
- Filenames are **lowercase**: `en.json`, `zh.json`, `zh-cn.json`

## Locale resolution order

Tried in order:

1. Query: `?lang=`
2. Cookie: `bunny_lang`
3. Session: `bunny_lang`
4. Header: `Accept-Language`
5. Default: `en`

## Region fallback

If the requested locale is `zh-cn`:

- Try `zh-cn.json`
- Fallback to `zh.json`
- Fallback to `en.json`

If a key is missing in the app catalog, it falls back to the framework catalog.

## Usage

```php
<?= BunnyPHP\Language::get('login') ?>
```

With interpolation (`{name}` style):

```php
<?= BunnyPHP\Language::get('welcome', ['name' => $nickname]) ?>
```
